## 应用作用

本系统是一款**局域网网络流量实时监控与安全分析工具**，主要功能包括：

1. **实时流量仪表盘** — 通过 Windows 性能计数器读取网卡真实吞吐量（下载/上传 Mbps），以动态曲线图展示，同时基于 netstat 连接数据统计实时协议分布
2. **协议分析** — 基于 Nmap 19919 条端口服务数据库，对所有活跃连接进行协议识别与占比分析（传输层 TCP/UDP + 应用层 HTTP/HTTPS/DNS/MySQL 等）
3. **告警管理** — 支持用户自定义流量阈值（Mbps），自动检测流量峰值；内置异常行为检测引擎（连接数飙升检测、端口扫描识别）
4. **局域网扫描** — 调用 Nmap 进行 Ping 扫描（快速主机发现）和端口扫描（500 端口高精度服务识别 + OS 指纹识别），支持端口对齐视图，一键对比所有设备的开放端口

## 开发背景

在现代办公和家庭网络环境中，局域网设备数量持续增长，网络流量构成日益复杂。用户面临以下痛点：

- **流量黑洞**：不知道自己网络的真实带宽使用情况，无法定位流量瓶颈
- **设备不可见**：局域网中连接了多少设备、每台设备开放了哪些端口，缺乏直观的管理界面
- **异常难发现**：端口扫描、连接数异常飙升等安全威胁缺乏实时告警机制
- **工具碎片化**：Wireshark 太重、nmap 只有命令行、路由器后台信息有限，缺少一个轻量级的整合方案

本系统将这些能力整合到一个简洁的 Web 界面中，双击即可启动，无需复杂配置。

## 使用背景

### 适用场景

| 场景 | 用途 |
|------|------|
| **家庭网络管理** | 查看有哪些设备连了家里 WiFi，检查陌生设备 |
| **办公网络运维** | 监控局域网各主机端口开放情况，发现未授权服务 |
| **网络故障排查** | 对比实时吞吐量与运营商带宽，判断是否带宽不足 |
| **安全自查** | 检测端口扫描行为、连接数异常飙升 |
| **学习研究** | 了解 TCP/IP 协议分布、端口服务映射、nmap 扫描原理 |

### 系统要求

- Windows 10/11（性能计数器依赖）
- Node.js 24+（服务端运行）
- Nmap 7.x（需预先安装，系统自动查找 `E:\Nmap\nmap.exe`、`C:\Program Files (x86)\Nmap\nmap.exe` 等路径）
- 无需管理员权限（部分功能受限，详见下文）

### 权限说明

| 功能 | 权限要求 |
|------|---------|
| 实时吞吐量 (Get-Counter) | 普通用户 |
| 连接追踪 (netstat) | 普通用户 |
| Ping 扫描 (nmap -sn) | 普通用户 |
| 端口扫描 (nmap -sS) | 需管理员权限（否则退化为 -sT 全连接扫描） |
| OS 指纹识别 | 需管理员权限 |

## 发展前景

### 近期规划

- **多网卡聚合**：同时监控有线 + 无线多块网卡的流量
- **历史数据持久化**：SQLite 存储每日流量数据，支持长期趋势分析
- **设备别名**：为扫描发现的设备设置自定义名称（如"客厅路由器"）
- **流量排行恢复**：基于按 IP 累计的真实流量数据排行

### 中期规划

- **进程级流量分析**：关联 netstat 连接的 PID，显示每个应用的流量消耗
- **应用层深度识别**：集成 nDPI 或同类库，超越端口号进行协议识别（识别跑在非标准端口的 HTTP/SSH 等）
- **邮件/Webhook 告警**：告警推送到邮箱或企业微信/钉钉

### 远期愿景

- **多节点协同**：在多台机器部署 Agent，统一汇聚到中央控制台
- **AI 流量基线**：基于机器学习的流量行为建模，识别零日威胁和 APT 攻击
- **跨平台支持**：扩展到 Linux/macOS（使用 /proc/net/dev、nftables 等替代 Windows 性能计数器）
